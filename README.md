# Grimshard

**▶ PLAY:** https://claude.ai/artifact/LyXXV5pthgdUzJStqMXSBX
**Backup:** https://raw.githack.com/lorenzocleton-sudo/Necrovilan/main/play/index.html

Grimshard (working title) is a turn-based, top-down 3/4 pixel-art necromancer
roguelite in the spirit of Stoneshard, built to play in a phone browser held
in landscape. Everything — sprites, tiles, fonts and sound — is generated by
code or inlined, so the whole game ships as one self-contained HTML file
(`play/index.html`) that makes no network requests. Stack: TypeScript, Phaser,
Vite + vite-plugin-singlefile, Vitest, ZzFX. Project memory lives in `docs/`
(STYLE, DECISIONS, PROGRESS).

Developer commands: `npm run dev`, `npm run build`, `npm run test`,
`npm run check`, `npm run scan` (external-URL scan), `npm run smoke`
(headless browser smoke test).
